# 🚦 Traffic Flow Prediction System

An AI-powered Traffic Flow Prediction System that forecasts traffic congestion using Machine Learning (LSTM) and provides a modern analytics dashboard for monitoring road conditions.

## 🚀 Features

- 📊 Real-time Traffic Dashboard
- 🤖 AI-based Traffic Prediction (LSTM)
- 🛣️ Road-wise Traffic Analysis
- 🌦️ Weather Impact Analysis
- 📈 Traffic Statistics & Trends
- 🗺️ Interactive Traffic Map
- 📜 Prediction History
- ⚙️ System Status Monitoring
- 🗄️ MySQL Database Integration
- 🔌 REST API Backend

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/kakaloorsanjaykrishna-cmd/Traffic-Flow-Prediction.git
cd Traffic-Flow-Prediction
```

### Backend Setup

```bash
cd backend

pip install -r requirements.txt

python app.py
```

### Frontend Setup

```bash
cd frontend

npm install

npm run dev
```

## 🧠 Machine Learning

The prediction engine uses an LSTM (Long Short-Term Memory) neural network trained on historical traffic data to forecast future traffic congestion levels.
